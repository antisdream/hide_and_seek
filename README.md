# 눈치숨: 수상한 잡화점

![밤의 잡화점에서 문구류 정령을 찾는 밤지기 모루](public/og.png)

**눈치숨**은 소리 없이도 PC와 모바일 웹에서 즐길 수 있는 실시간 사물 숨바꼭질 게임입니다. 숨는 팀 · 틈새정령은 연필·노트·테이프 같은 사물로 숨어 진열 미션을 수행하고, 술래 · 밤지기는 기준 배치의 어색함과 움직임 흔적을 살펴 수상한 사물을 찾아냅니다.

## 주요 기능

- 자리가 있는 공개 대기실로 들어가는 4~10명 빠른 매칭
- 새 대기실을 연 뒤 방장이 쉬움·보통·어려움 AI를 한 명씩 추가·삭제하는 `방 만들기`
- 사람과 AI를 합쳐 최대 10명까지 참여하는 대기실, 초대 링크·코드 참가와 게임 시작 전 채팅
- 3라운드마다 바뀌는 `밤의 문구점`, `달빛 물류창고`, `별빛 포장공방`
- 이동 공백을 줄인 밀집형 맵, 다양한 구조물과 양방향 문·포탈 이동
- 숨는 팀 · 틈새정령은 감춘 채 술래 · 밤지기만 기준 배치를 미리 탐색하는 기억 단계
- 이동 입력을 완전히 막는 위치 고정, 맵 전체 같은 종류 중 무작위 1회 자리바꿈, 진열 미션과 관찰 렌즈
- 경기 중 자유 채팅 대신 사용하는 역할별 팀 신호
- 숨는 팀 · 틈새정령 6.5·술래 · 밤지기 9.5의 빠른 이동, 약 46% 추격 우위와 프레임 연속 로컬 이동·30Hz 서버 좌표 시간 보간
- 직전 라운드에 술래였던 이용자를 연속 배정하지 않는 역할 순환과 20점 단위 생존 점수
- 소개 화면의 귀여운 모루는 보존하고 실제 경기에서는 어두운 망토·균열 가면·발광 눈을 사용하는 밤지기 외형
- 마우스 드래그·휠로 살피는 기준 배치와 시각적인 마지막 추격 경보
- 역할을 크게 알려주는 10초 역할표, 첫 플레이 말풍선과 마우스·키보드·터치 도움말
- 실제 게임 캡처와 번호 표시로 입장부터 결과까지 설명하는 게임 방법 페이지
- 움직임 파문·고정 오라·행동별 색상 효과와 맵마다 다른 바닥·구조물·사물 외형
- 접속한 PC의 현재 IP·호스트명을 자동으로 따르는 같은 네트워크 공유
- 10초 재접속 유예와 방장 이전

## 패치노트

패치 버전은 공개 게임 기능의 변화 단위를 `0.001`처럼 세 자리 숫자로 기록하고, 날짜는 `연-월-일`에 해당하는 `YYYY-MM-DD` 형식을 사용합니다. 아래 내용은 내부 작업 기록이 아니라 이용자가 체감할 수 있는 변경 사항을 기준으로 정리했습니다.

### 0.012 · 2026-08-22 · 부드러운 이동과 10인 대기실

- 선반 모서리를 실제 캐릭터의 원형 충돌에 맞춰 계산하고, 이동 거리를 작은 고정 구간으로 나눠 서버와 화면 주사율이 달라도 같은 경로를 따르게 했습니다.
- 일시적인 긴 프레임의 이동 시간을 버리지 않으며, 서버 좌표 보정도 구조물 충돌 계산을 통과하게 해 선반 안으로 밀려 들어갔다가 튕기는 현상을 막았습니다.
- 현재 키 입력을 과거 서버 좌표에 소급 적용하지 않고 서버가 실제로 확정한 좌표만 기준으로 삼아, 급회전과 방향 전환 때 잘못된 경로가 만들어지지 않게 했습니다.
- 이동 입력 확인 주기를 0.05초로 줄여 키를 누르거나 방향을 바꿀 때의 반응을 빠르게 했습니다.
- `빠른 매칭`은 새 방을 무조건 만드는 대신 자리가 있는 공개 대기실을 찾아 합류하며, 빈자리가 없을 때만 새 공개 대기실을 엽니다.
- 별도의 AI 방 선택 없이 `방 만들기`로 최대 10명 대기실을 열고, 방장이 쉬움·보통·어려움 AI를 필요한 만큼 한 명씩 추가하거나 삭제할 수 있게 했습니다.
- 대기실에 텍스트 채팅을 추가해 참가자끼리 인원과 AI 구성을 의논하고 준비 여부를 맞출 수 있습니다.
- 참가자의 연결이 끊기면 시작 준비를 취소하고, 공개방 방장이 재연결되는 동안에는 해당 방을 빠른 매칭에서 잠시 제외한 뒤 재연결 또는 방장 이전에 맞춰 자동으로 다시 엽니다.
- 초대 링크·코드, 참가자 목록, 준비 상태와 AI 관리 기능을 한 대기실 흐름에서 이해할 수 있도록 안내 문구를 정리했습니다.

### 0.011 · 2026-08-22 · 끊김 없는 조작과 통합 친구·AI 방

- 서버와 브라우저가 하나의 하위 단계 충돌 계산을 사용하도록 통합해 선반 모서리에서 안쪽으로 겹쳤다가 튕겨 나오는 현상을 막았습니다.
- 내 캐릭터는 30Hz 서버 좌표가 도착할 때만 움직이는 대신 화면 프레임마다 계속 전진하고, 이동을 멈춘 뒤에만 작은 좌표 차이를 정리하도록 바꿨습니다.
- `위치 고정`을 누르는 즉시 키·터치 입력과 화면 예측을 모두 멈추며, 이동 신호가 반복 수신돼도 명시적으로 고정을 해제하기 전에는 서버 위치가 변하지 않습니다.
- `무작위 자리바꿈`은 거리와 관계없이 맵 전체 같은 종류 사물 중 하나를 균등하게 선택하며 라운드당 한 번만 사용할 수 있습니다.
- 자리바꿈 도착 위치는 숨는 팀에게만 보여주고, 술래에게는 좌표 없는 사건 문구만 표시합니다. 같은 사물의 식별자도 기존 위치에 남기고 내부 이동 표식을 비식별화해 전후 좌표 비교만으로 정답을 좁히지 못하게 했습니다.
- 별도의 친구방·AI 방 선택을 없애고, 하나의 `친구·AI 방 만들기`에서 AI 난이도를 고르도록 정리했습니다. 혼자면 AI 세 명이 참여하고 친구가 들어오면 AI가 한 명씩 빠집니다.
- 역할 이름과 지금 할 일, 현재 고정 상태, 단계별 말풍선, 버튼 도움말의 글자와 문구를 처음 이용자도 바로 이해하도록 보강했습니다.
- 세 맵의 바닥 문양·구조물 장식·사물 실루엣을 테마별로 구분하고, 움직임 파문·고정 오라·포탈·자리바꿈·정답 효과를 색과 움직임으로 구별했습니다.
- 화면 움직임 감소 설정을 사용하는 이용자에게는 반복 애니메이션 대신 정적인 강조 상태를 제공합니다.

### 0.010 · 2026-08-21 · 부드러운 이동과 난이도별 행동 AI

- 게임 좌표는 React 화면 갱신을 기다리지 않고 Phaser가 30Hz 상태를 즉시 받게 하고, 점수·시간 UI는 10Hz로 분리해 불필요한 전체 재렌더링을 줄였습니다.
- 다른 참가자는 시간표가 붙은 좌표 버퍼로 두 서버 틱 사이를 보간하고, 잠깐 늦은 패킷은 최대 두 틱까지만 예측해 이동 간격을 일정하게 만들었습니다.
- 내 캐릭터는 키를 누르는 즉시 서버와 같은 속도·충돌 규칙으로 예측 이동한 뒤 권위형 서버 좌표로 부드럽게 보정합니다.
- 이미 보간된 캐릭터를 카메라가 다시 늦게 따라가던 이중 완화를 없애고 정수 픽셀 반올림도 사용하지 않도록 정리했습니다.
- 기존 혼자 연습을 `AI 방`으로 확장해 쉬움·보통·어려움 난이도를 선택할 수 있고, 친구가 초대 링크로 합류하면 AI가 한 자리씩 빠져 사람과 AI 합계 네 명을 유지합니다.
- AI는 벽 너머의 정답을 아는 대신 난이도별 시야, 반응시간, 라운드 내 기억, 이동속도와 오판률로 순찰·추적·확인·은신·도주·자리바꿈을 판단합니다.
- 사람과 AI를 같은 역할 이력으로 관리해 직전 라운드에 술래였던 이용자는 다음 라운드에 연속 배정하지 않고, 세 라운드에서 역할이 순환하게 했습니다.
- 틈새정령은 승패와 관계없이 수색에서 살아남은 시간 구간에 따라 `20·40·60·80점` 중 하나를 받고, 결과 화면에 이번 라운드 생존 점수가 따로 표시됩니다.

### 0.009 · 2026-08-21 · 빠른 이동과 위협적인 밤지기

- 숨는 팀 · 틈새정령 이동속도를 5.0에서 6.5, 술래 · 밤지기를 7.8에서 9.5로 높여 두 역할의 이동 공백을 줄였습니다.
- 술래 · 밤지기의 직선 추격 우위는 약 46%로 유지해 숨는 팀도 포탈과 구조물을 활용해 도망칠 수 있게 했습니다.
- 서버 위치 갱신과 입력 전송을 초당 20회에서 30회로 높이고, 키 입력 시작·해제 즉시 방향을 전달하도록 바꿨습니다.
- 좌표 보간 응답을 빠르게 하고 카메라 추적 지연과 정수 픽셀 반올림을 줄여 이동 화면이 뚝뚝 끊겨 보이는 현상을 완화했습니다.
- 실제 경기의 밤지기에게 어두운 망토, 뿔, 균열 가면, 발광 눈과 아바타별 오라 색을 적용했습니다.
- 기존 귀여운 밤지기 모루 디자인은 입장 전 소개 화면에 원본 모습으로 계속 보존합니다.

### 0.008 · 2026-08-20 · 역할 안내와 인원별 라운드 개선

- 4인 기준 한 라운드를 역할 확인 10초, 숨기·기준 배치 확인 35초, 수색 125초, 결과 10초의 총 180초로 조정했습니다.
- 참가자가 한 명 늘 때마다 수색 시간이 15초 추가되며, 라운드가 시작된 뒤 인원이 바뀌어도 현재 라운드 시간은 갑자기 변하지 않습니다.
- 역할 확인 전에 서버가 역할을 확정해 본인의 역할·승리 조건·첫 행동 세 가지를 큰 화면으로 보여주고, 다른 참가자의 역할과 위치는 숨깁니다.
- 숨는 팀 · 틈새정령 속도는 5.0으로 유지하고 술래 · 밤지기만 7.8로 높여 수색 이동 시간을 줄였습니다.
- 세 맵의 면적을 약 9~10% 줄이고 사물 수와 양방향 포탈 2쌍을 유지해 빈 이동 구간을 줄였습니다.
- 포탈 표시에 도착지 이름을 함께 적어 처음 보는 맵에서도 이동 결과를 예상할 수 있게 했습니다.
- 첫 플레이 말풍선, 항상 다시 열 수 있는 역할 도움말과 스킬별 상세 설명을 추가했습니다.
- 스킬 설명은 마우스 올리기, 키보드 포커스와 모바일 터치를 모두 지원합니다.
- 입장부터 결과까지 실제 멀티플레이 화면을 촬영해 번호 표시와 단계별 설명이 있는 게임 방법 페이지를 만들었습니다.

### 0.007 · 2026-08-20 · 유동 네트워크 자동 연결

- Docker 이미지에 `localhost` 게임 서버 주소를 고정하지 않고, 브라우저가 접속한 IP 또는 호스트명을 자동으로 사용하게 했습니다.
- 네트워크가 바뀌어 PC의 사설 IP가 달라져도 Docker 이미지를 다시 만들거나 설정 파일의 IP를 수정할 필요가 없습니다.
- 초대 링크도 방장이 실제로 접속한 주소를 기준으로 만들어 친구가 같은 네트워크에서 그대로 열 수 있습니다.
- 게임 서버는 `same-host` 정책으로 같은 IP·호스트의 웹 Origin을 자동 허용하고, 다른 호스트에서 보낸 요청은 거부합니다.
- 일반 HTTP 사설 IP에서도 방 입장용 ID 생성과 초대 링크 복사가 동작하도록 브라우저 호환 경로를 추가했습니다.
- 외부 도메인이나 별도 게임 서버를 사용할 때는 기존 환경 변수로 명시적 주소를 우선 적용할 수 있습니다.

### 0.006 · 2026-08-20 · 친구방 참가와 추격 템포 개선

- 입장 화면에서 친구가 보낸 초대 코드 또는 전체 초대 링크를 직접 붙여 넣어 방에 참가할 수 있게 했습니다.
- 술래 · 밤지기의 이동속도를 숨는 팀 · 틈새정령보다 30% 빠르게 조정해 추격 역할의 우위를 분명히 했습니다.
- 확인 스티커 재사용 대기를 정답 1.2초, 오답 3초, 집중력 소진 6.5초로 늘리고 남은 시간을 화면에 표시합니다.
- 한 라운드를 카운트다운 3초, 숨기·기억 18초, 수색 55초, 결과 8초로 압축했습니다.
- 술래 · 밤지기가 기준 배치를 전체 보기로 시작해 마우스 드래그로 이동하고 휠로 확대·축소할 수 있게 했습니다.
- 수색 마지막 15초에 붉은 테두리, 점멸 타이머와 문구로 무음 위험 경보를 제공합니다.
- 웹과 게임 서버를 함께 실행하고 두 서비스의 상태를 확인하는 `hide_and_seek` Docker 컨테이너를 추가했습니다.

- 위치 고정 상태에서 키를 계속 누르거나 자리바꿈을 사용해도 고정이 임의로 풀리지 않는지 확인합니다.
- 맵 전체 무작위 자리바꿈이 세 맵과 세 난이도에서 도착지를 충분히 다양하게 만드는지 기록합니다.

- 정답 1.2초·오답 3초·집중력 소진 6.5초의 확인 대기가 전수 클릭을 충분히 줄이는지 기록합니다.

## 게임 시작 방법

1. `/game`에서 별명을 입력합니다.
2. 처음이라면 입장 화면의 `실제 게임 화면으로 차근차근 배우기`를 열어 역할과 조작을 확인합니다.
3. 친구 또는 AI와 하려면 `방 만들기`를 선택해 최대 10명이 참여할 대기실을 엽니다.
4. 방장은 대기실에서 쉬움·보통·어려움 AI를 필요한 만큼 한 명씩 추가하거나 삭제합니다.
5. 초대 링크를 친구에게 보내고, 대기실 채팅으로 인원과 AI 구성을 의논한 뒤 각자 `준비 완료`를 누릅니다.
6. 링크를 열기 어렵다면 받은 초대 코드나 링크를 입장 화면의 `초대 코드로 참가`에 붙여 넣습니다.
7. 공개 이용자와 플레이하려면 `빠른 매칭`을 선택합니다. 자리가 있는 공개 대기실에 먼저 합류합니다.

### 라운드별 맵

| 라운드 | 맵 | 특징 |
|---:|---|---|
| 1 | 밤의 문구점 | 긴 진열대와 계산대·창고 연결 |
| 2 | 달빛 물류창고 | 상자 더미와 선반 사이의 교차 통로 |
| 3 | 별빛 포장공방 | 작업대와 리본 통로가 나뉜 구조 |

각 맵의 문과 포탈에는 도착지 이름이 함께 표시되며, 들어가면 연결된 다른 구역으로 즉시 이동합니다. 술래 · 밤지기는 숨기 35초 동안 숨는 팀 · 틈새정령을 볼 수 없으며, 전체 기준 배치를 마우스로 이동·확대하거나 직접 포탈을 통과하며 구조물과 기본 사물 위치를 기억할 수 있습니다.

## 기본 규칙

| 역할 | 목표 | 주요 행동 |
|---|---|---|
| 숨는 팀 · 틈새정령 | 수색 종료까지 한 명 이상 생존 | 이동, 위치 고정, 맵 전체 무작위 자리바꿈 1회, 진열 미션, 팀 신호 |
| 술래 · 밤지기 | 제한시간 안에 모든 틈새정령 발견 | 기준 배치 탐색, 포탈 이동, 사물 확인, 관찰 렌즈, 팀 신호 |
| 발견된 틈새정령 | 남은 팀 지원 | 팀 신호 |

4인 한 라운드는 역할 확인 10초, 숨기·기준 배치 확인 35초, 수색 125초, 결과 10초의 총 180초입니다. 5명부터는 참가자가 한 명 늘 때마다 수색 시간만 15초 추가되어 10명에서는 한 라운드가 최대 270초가 됩니다. 숨는 팀 · 틈새정령을 모두 찾으면 남은 시간과 관계없이 결과로 넘어갑니다.

숨는 팀 · 틈새정령은 초당 6.5칸, 술래 · 밤지기는 초당 9.5칸을 이동합니다. 방향이 바뀌면 입력을 즉시 전송하고 0.05초마다 유지 상태를 확인합니다. 서버는 초당 30회 판정하며, 내 캐릭터는 서버와 같은 원형 모서리 충돌 규칙으로 화면 프레임마다 움직입니다. 서버 좌표와 차이가 생겨도 진행 방향의 반대로 당기지 않고 한 프레임 보정량을 제한하며, 다른 참가자는 서버 시간 기준으로 프레임 사이를 연결합니다. 확인 스티커는 정확한 확인 뒤 1.2초, 잘못된 확인 뒤 3초, 집중력을 모두 쓴 뒤 6.5초 동안 다시 사용할 수 없습니다. 게임 수치의 기준은 [`shared/game-rules.ts`](shared/game-rules.ts)입니다.

수색에서 버틴 시간은 네 구간으로 나눠 `20·40·60·80점`으로 표시됩니다. 전원 발견 여부와 관계없이 각 틈새정령이 버틴 구간만큼 받고, 틈새정령 팀이 시간 종료로 승리하면 기존 팀 승리 보너스 50점이 별도로 더해집니다.

### 대기실 AI 관리

| 난이도 | 행동 특징 | 공정성 기준 |
|---|---|---|
| 쉬움 | 반응이 느리고 움직임 단서를 자주 놓치며 오판이 많음 | 사람 역할보다 낮은 이동속도 |
| 보통 | 시야·기억·실수를 균형 있게 사용 | 사람과 비슷하지만 조금 낮은 이동속도 |
| 어려움 | 단서를 빨리 포착하고 오래 추적하며 적극적으로 도주 | 사람 역할의 최고 속도를 넘지 않음 |

방을 만들면 사람과 AI를 합쳐 최대 10명이 참여할 수 있습니다. 방장만 대기실에서 세 난이도의 AI를 한 명씩 추가하거나 삭제할 수 있으며, 친구가 합류해도 AI 구성은 자동으로 바뀌지 않습니다. 참가자들은 대기실 채팅으로 구성을 정한 뒤 준비합니다.

AI는 별도 머신러닝 모델을 훈련하거나 접속자의 데이터를 학습하지 않습니다. 서버에서 현재 라운드의 시야 안 단서와 짧은 기억만 사용하는 행동 AI이므로, 화면 밖이나 선반 너머에 숨은 정답 위치를 미리 알 수 없습니다. 사람과 AI는 같은 역할 순환·점수 규칙을 사용하며, 세부 프로필은 [`shared/ai-rules.ts`](shared/ai-rules.ts)에 있습니다.

컨테이너 이름은 `hide_and_seek`이며 다음 주소를 함께 엽니다.

- 웹 게임: `http://localhost:3000`
- 게임 서버 상태: `http://localhost:2567/health`

같은 공유기·사내망에 있는 사람에게는 `ipconfig`에서 기본 게이트웨이가 있는 어댑터의 IPv4를 확인한 뒤 `http://<현재 IPv4>:3000/game` 형식으로 공유합니다. 예를 들어 IP가 `192.168.0.41`이면 `http://192.168.0.41:3000/game`입니다. IP가 바뀌면 새 IP로 접속 링크만 다시 알려주면 되며 Docker 재빌드는 필요하지 않습니다.

방장이 위 IP 주소로 게임에 접속한 상태에서 방을 만들고 `복사`를 누르면 같은 IP가 들어간 초대 링크가 자동 생성됩니다. 다른 기기에서 접속되지 않을 때는 두 기기가 같은 네트워크인지와 Windows 방화벽에서 TCP `3000`, `2567` 인바운드 연결이 허용됐는지 확인합니다.

상태와 로그를 확인하거나 종료할 때는 다음 명령을 사용합니다.

```bash
docker compose ps
docker compose logs -f hide-and-seek
docker compose down
```
